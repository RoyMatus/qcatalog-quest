# QCatalog Cards v1 — утверждённый вариант 02

**Для реализации использовать именно ресурсы из этого каталога.** Выбран светлый вариант «Карточки»: тёплый фон, синяя основная кнопка, левая навигация, крупная сетка игр. Не заменять его вариантами «Панель» или «Фокус», не генерировать другой набор иконок и не подбирать приблизительные цвета.

## Источник истины

1. `tokens.json` — точные цвета, размеры и типографика.
2. `android/res/` — готовые Android values, VectorDrawable и фоны с префиксом `qc_`. Их необходимо импортировать в ресурсы приложения и использовать в реализации.
3. `screens/*.svg` — пять редактируемых макетов экранов 1280 × 800.
4. `icons/*.svg` — исходники тех же иконок для дизайна. Android использует их эквиваленты VectorDrawable.
5. `preview.html` — обзор всех экранов, открывается локально без сети.
6. `approved-reference.png` — исходный концепт с тремя вариантами; утверждён **только средний, № 02**. При расхождении приоритет у tokens и SVG этого набора: они уточняют поведение и увеличивают читаемость.

Приложение в этой задаче не изменено. Макеты не являются готовыми Android layout-файлами: компоновку и обработчики нужно реализовать отдельно.

## VR-взаимодействие

- Базовая область 1280 × 800 dp — ориентир компоновки, не фиксированный размер окна и не гарантия углового размера в VR.
- Минимальная область нажатия 64 × 64 dp, кнопки высотой 64 dp. Базовый текст 22 sp, вторичный не меньше 20 sp. Проверить читаемость на реальном Quest 3S при обычном размере и расстоянии окна.
- Вся карточка игры — одна большая цель. Название максимум две строки, затем многоточие; полное название доступно в карточке игры.
- Три колонки при ширине окна от 1180 dp, две от 880 dp, одна ниже. Ниже 880 dp левое меню заменяется крупной кнопкой «Разделы», открывающей список тех же разделов; все четыре названия доступны без иконок-загадок.
- Вертикальная прокрутка внутри контента. Навигация и поиск закреплены. Не использовать горизонтальную прокрутку каруселей.
- Наведение лучом и фокус: внешняя синяя рамка 3 dp без изменения геометрии. Нажатие: затемнение заливки. Активный раздел: заливка selected и текстовая метка. Ошибка/успех отличаются текстом и знаком, а не только цветом.
- Каждое действие подписано; `contentDescription` для самостоятельных иконок, декоративные иконки исключить из accessibility. Не дублировать название в озвучивании.
- Без функций, доступных только при наведении, долгом нажатии или жесте. Нет обязательного перетаскивания.
- Системный sans-serif, без загрузки шрифтов из сети. Увеличение системного размера текста не должно обрезать кнопки.

## Каталог и карточка игры

Реальные названия, версии, размеры и описания берутся из каталога. Данные макетов демонстрационные.
Обложки и описания загружаются динамически только для видимых карточек/открытой игры, хранятся только в ограниченном RAM-кеше и не записываются на диск шлема. Фоновая массовая загрузка и массовый перевод запрещены.
До загрузки и при ошибке используется `qc_cover_placeholder`, а не нарисованные обложки концепта.
Если русское описание недоступно, показывать честное состояние; не выдумывать перевод и не менять существующую политику перевода без отдельного решения.
В карточке одна основная кнопка: «Установить», «Обновить» или «Открыть» по фактическому состоянию пакета. Отдельно показывать установленную и доступную версии.

## Связь с issue #1: прогресс и очистка

1. Скачивание: байты/общий объём, процент и скорость. «Пауза» и «Продолжить» относятся к скачиванию; ручная пауза сохраняется при перезапуске.
2. Установка APK: точный процент только при наличии достоверных данных Android. Иначе неопределённый индикатор и «Устанавливается…», без выдуманного процента/ETA и без «Пауза». Когда требуется подтверждение — «Подтверди установку в системном окне».
3. Копирование данных: отдельный прогресс байт/общий объём, затем проверка. Не показывать кнопку паузы, пока безопасное продолжение копирования не реализовано и не проверено.
4. Успех только после подтверждения установки нужной версии и завершения обязательных файлов данных.
5. После успеха удалить предложение обновления и завершённую задачу из активного списка. Установленная игра остаётся в библиотеке.
6. Удалять только скачанные установочные файлы конкретной завершённой задачи из папки QCatalog. Не удалять рабочие OBB, установленный пакет, сохранения, моды и данные других задач.
7. Во время очистки показывать «Удаляем установочные файлы…». Текст об удалённых файлах появляется только после фактического успеха очистки.
8. При ошибке установки сохранять файлы и запись, показывать причину и «Повторить».
9. При ошибке очистки игра уже обновлена: не предлагать устанавливать её снова. Показать отдельное предупреждение и «Повторить очистку». Предложение обновления при этом уже убрано.
10. Уведомление об успехе 6 секунд, не блокирует действия и не является единственным подтверждением: актуальная версия остаётся в библиотеке.

Состояния:
`queued → downloading ↔ paused → downloaded → installing → copying → verifying → cleanup → done`.
Переходы с ошибками: `installing/copying/verifying → error` с сохранёнными файлами; `cleanup → cleanupError` с повтором только очистки.
Некоторые шаги пропускаются, если дополнительных данных нет.

## Приёмка

- Сравнить реализованные экраны с SVG при базовом размере; проверить токены и импорт именно поставленных ресурсов.
- Проверить контроллерами Quest: выбор карточки, поиск, смена раздела, пауза/продолжение, подтверждение установки, повтор после ошибки.
- Проверить длинные русские названия, крупный системный шрифт, узкое окно, пустую библиотеку, отсутствие сети и отсутствующую обложку.
- Проверить успешную установку APK с данными, отказ Android, конфликт подписи, нехватку места, ошибку очистки, перезапуск.
- Проверить отсутствие файлов описаний/обложек в кеше на диске.

## Условия использования набора

SVG-иконки, заглушка и макеты созданы специально для этого проекта; сторонний пакет иконок или шрифтов не включён. Реальные игровые обложки не включены. `approved-reference.png` — AI-концепт, используется только как визуальный ориентир, не как ресурс внутри приложения.
Не добавлять PNG концепта, HTML-превью и SVG экранов в APK. В APK идут Android ресурсы; реальные изображения приходят из каталога.
